# Harborline Studio Handbook

## Opening the studio
The studio opens at 09:00 and closes at 18:00. The alarm code is kept in the
safe, not in this handbook.

## Client work
Every client project gets a folder in the project drive, a signed agreement in
`contracts/`, and an invoice in `invoices/` raised on the first working day of
the month.

## Backups
The studio server is backed up to the local NAS. The backup password is shared
only with the two studio partners.
