# Harborline Studio brand guidelines

- Name: always written as "Harborline Studio", never "Harbourline".
- Primary colour: Deep Harbour `#12405A`.
- Accent colour: Brass `#C9A227`.
- Typeface: Söhne for headings, system serif for long copy.
- Logo lockup: wordmark left, compass mark right, minimum width 24 mm.
